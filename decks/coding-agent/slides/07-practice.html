06 — THE PRACTICE让协作更有效

THREE USEFUL HABITS

好作品，来自好的协作。

一点点更好的输入，
会带来很不一样的结果。

01
◉

给它真实的上下文

目标、受众、参考作品、现有素材；告诉 Agent 什么重要，也告诉它什么不能变。

TRY THIS“这页是给新用户看的，
请保留现有品牌色。”
